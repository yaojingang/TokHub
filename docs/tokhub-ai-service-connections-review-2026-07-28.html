当前完整链路

1. 选择服务

从固定注册表选择服务商、地域和产品线。Endpoint 由服务端生成，客户端不能提交任意地址。

2. 导入凭证

仅接受官方开发者 API Key。用户确认最小验证可能产生费用。

3. 按模型验证

模型列表探测最多一次，配置模型最多四并发验证，整组最多 25 秒。

4. 加密保存

AES-256-GCM 保存密文，独立 HMAC Key 生成指纹，响应只展示 mask。

5. 快速中转

只选已验证模型，事务创建受管通道、网关和调用密钥，幂等结果保留 10 分钟。

运行时读取凭证时会再次检查连接所有者状态、个人工作区成员关系、连接状态、模型启用状态和模型验证状态。删除连接、删除用户、停用用户或移除成员关系都会切断这条链路。

两套系统的关键差异

维度sub2apiTokHub评审判断
产品重心账号池、订阅额度分发和高吞吐调度。渠道观测、工作区网关、个人凭证连接和治理。两者可以共享调度思想，数据模型和用户边界需要保持各自语义。
凭证来源覆盖 OAuth、Cookie、Session 和多类账号凭证，项目主页明确提示服务商条款和封号风险。本轮只接受官方开发者 API Key，拒绝密码、验证码、浏览器 Cookie 和消费者登录态。TokHub 当前策略更适合普通用户自助接入，也减少条款和账号安全风险。
静态凭证存储当前账号仓储以 JSONB 保存 credentials，并在响应层集中脱敏。凭证使用版本化 AES-256-GCM 加密，HMAC 指纹和加密 Key 分离。TokHub 的静态凭证保护更完整；sub2api 的集中脱敏注册表值得吸收。
账号状态机区分 active、schedulable、过期、限流、过载、临时不可调度和会话窗口。连接主状态为 active、attention、disabled、deleted；模型有 verified、unverified、disabled。TokHub 已补模型级状态，运行时冷却和过载状态仍有差距。
401、403、429 处理按服务商和错误语义刷新、冷却、暂停或降低调度资格。当前统一映射为认证错误、限流、上游不可用，并开启 30 秒熔断。TokHub 需要连接级错误状态和可持久化冷却时间。
令牌刷新有刷新器注册表、并发和 QPS 门控、刷新锁、失败阈值和缓存失效。首版只支持 API Key，不做 OAuth 自动刷新。等正式 OAuth 上线时复用 sub2api 的刷新治理思路。
调度一致性有调度 Outbox、缓存失效、并发控制和账号选择测试。沿用网关路由和 Redis 计划缓存，连接状态变更直接影响数据库查询。规模扩大后需要 Outbox 或版本化缓存失效。
用户交付偏管理端账号池和 API 分发。普通用户在个人工作区完成连接、验证、轮换、删除和快速中转。TokHub 的个人用户闭环更完整。

后续升级顺序

优先级升级项参考 sub2api 的部分验收标准
P0服务商级创建和运行开关、deployment mode、策略复核期限账号类型和服务商配置集中治理七家均可独立停止新增和运行；策略过期自动禁止新增；自托管和托管模式有不同允许列表。
P0连接运行时状态机rate_limit_reset_at、overload_until、临时不可调度和错误分类401 进入重新授权，403 区分权限、地域和策略，429 按重置时间冷却，5xx 采用有上限退避。
P1模型能力目录和稳定错误能力探测和模型可用性测试文本、流式、工具、多模态、结构化输出等能力按模型保存；未验证能力返回 unsupported_feature。
P1连接并发、公平队列和请求 attempt账号并发、QPS 门控、调度选择和故障切换每个连接有并发上限；排队可观测；每次候选尝试有结构化事件；重试不会形成无界风暴。
P1密钥批量重加密和旧 Key 退役集中凭证持久化和生命周期管理思路后台按批次把旧 Key ID 密文迁到 active Key；有进度、失败重试和旧 Key 安全删除门禁。
P1共享工作区凭证授权账号池的权限边界和调度资格连接所有者发起 route_only grant，工作区管理员接受；运行时检查授权、成员关系和双方状态；任一方撤销后关联路由和 Key 立即失效。
P2模型目录 TTL、创建连接幂等和细分监控缓存失效、Outbox 和分页任务目录过期阻止新启用；创建连接支持幂等 Key；监控按服务商、模型和连接汇总且控制标签基数。
P2正式 OAuth刷新器注册表、刷新锁、QPS 门控和熔断每家服务商经过官方授权和条款审核后独立上线；PKCE、state、回调绑定、重放和刷新并发测试通过。
HMAC 指纹 Key 轮换期间，同一明文凭证可能分别留下旧指纹和新指纹。批量重加密阶段应同步重算指纹，并在旧指纹清零前保留跨 Key ID 的重复检查策略。
